# DA2 라이브 깊이 경계 보정 반경 4/8 비교

RTX 5090에서 Small과 Base 각각 동일한 FP16 추론 결과를 두 렌더러에 전달했다. 두 렌더러는 해당 모델의 라이브 설정을 공유하고 반경만 4/8로 달리했다. 입체감 0.5, VFG 끔, 60 Hz 입력 타임스탬프, 독립된 시간 이력, detail 후처리와 네이티브 Full SBS 출력을 사용했다. 4K120 소스는 한 프레임씩 건너뛰었다. 5개 클립 × 2개 모델 × 48프레임으로 총 480쌍을 비교했다. 처음 6프레임은 통계에서 제외하고 반경 실행 순서는 매 프레임 바꿨다.

GPU 시간은 CUDA 이벤트 5–6 사이의 가이드 단계 중앙값이다. 호스트 입력과 결과 읽기가 포함된 진단 재생에서 얻었으며 실제 캡처 FPS 및 시스템 전력은 별도 측정 대상이다. 윤곽 시차 잔차는 최종 수평 이동량을 가로·세로 1/4 크기로 평균 축소한 뒤 역방향 광류로 이전 프레임을 정렬해 구했다. 입력 RGB의 윤곽이 있고 정렬 후 명도가 비슷한 영역에서 시차 변화 절댓값을 평균했다. 값이 작으면 해당 지표상 변화가 적지만, 정당한 깊이 변화와 과도한 평활화도 포함될 수 있다. 깊이 정답, 미세 윤곽 정확도, 실물 시청 편안함은 이 수치만으로 판정하기 어렵다.

경계 보정 비용이 우선이면 두 모델 모두 반경 4가 유리하다. 반경 8은 모든 조합에서 잔차가 작았고, 4K Jockey의 두 출력은 눈당 윤곽 평가 영역에서 RGB 채널 차이가 3/255를 넘은 픽셀이 약 6.5%였다. 사용자가 중요하게 본 일렁임을 기준으로 통일 여부를 결정하려면 이 장면의 실물 확인이 유용하다. 테스트 당시 기본값은 Small 4, Base 8이다.
