# 완성된 네이티브 SBS 재사용

준비된 RTX 5090 앱의 DA2 Small·Base, CUDA 네이티브 detail 출력, VFG 끔에서 적용했다. 캡처가 들어오면 기존 장면 썸네일로 달라진 화면을 먼저 걸러낸다. 썸네일이 같으면 전체 RGB를 정확히 비교한다. 직전 추론 입력과 RGB가 같은 경우에만 마지막으로 제출한 좌우 텍스처를 계속 표시할 수 있다. 입력 부재는 기존 대기 경로에서 처리한다.

4회 연속 동일 입력마다 렌더 후 GPU에서 평활 깊이와 정규화 깊이의 잔차, 실제 사용 중인 두 범위 끝점의 변화량, 가장자리 마스크의 목표·표시 값을 확인한다. FP32의 정지 EMA가 목표값과 2.38e-7 떨어진 상태에서 더 이상 변하지 않는 사례가 있어 깊이 잔차 허용치는 8×FP32 epsilon, 범위 끝점 허용치는 범위 폭의 2e-7이다. 이 조건을 만족하면 동일 입력이 이어지는 동안 표시 범위를 고정하고 광류 참조를 갱신한다. 이후 전체 투영 깊이가 이전 검사와 정확히 일치하고 마스크도 수렴하면 재사용한다. 추가 GPU 상태는 이 검사에서 처음 할당하는 픽셀당 float 하나와 범위용 double 두 개다.

재사용 중에는 기존 텍스처와 프레임 ID가 유지된다. 새 추론·투영·복사·게시를 생략하고, 연속 입력에서는 소스 시간 기준 1초 뒤 실제 렌더로 다시 확인한다. 좌표 한 곳의 RGB 변화라도 다음 처리 대상 캡처에서 재사용을 해제한다. 크기 변경·잘린 시간 이력·장면 전환·새 세션에서도 다시 판정한다. VFG 보간 프레임과 RowFlow 출력은 이 경로를 사용하지 않는다.

## 픽셀 비교

`v1/check_static_sbs_pixels.py`에서 공개 FloorballGame을 1280×720 입력으로 사용했다. 모델별 647프레임에 정지, 32×32 썸네일에 나타나지 않는 한 픽셀 변경, 실제 움직임, 다시 정지를 포함했다. 동일한 추론 토큰과 시각을 사용해 세 렌더러의 네이티브 2560×720 RGBA 출력을 비교했다.

| 모델 | 재사용한 입력 | 움직임 뒤 정지 구간의 재사용 | 매번 렌더한 새 수렴 규칙과 다른 채널 | 이전 빌드와 다른 채널 / 최대 차이 |
| --- | ---: | ---: | ---: | ---: |
| Base | 389 | 272 | 0 | 11,421 / 8단계 |
| Small | 432 | 315 | 0 | 10,595 / 24단계 |

이전 빌드와의 차이는 각 모델에서 비교한 RGBA 약 47.7억 채널 값 중 집계했다. 정지 수렴 처리를 추가했으므로 이전 빌드와의 비트 일치는 보장하지 않는다. 실제 Owl3D에서의 주관적 화질은 평가하지 않았다. 프레임 재사용과 관계없이 같은 수렴 규칙을 적용한 경로 간에는 이 구간의 모든 픽셀이 일치했다.

## 실제 창 캡처

`v1/check_static_sbs.py`로 테스트가 소유한 공개 영상 창만 WGC로 캡처했다. 입력 3840×2160, 네이티브 출력 7680×2160, 목표 60 FPS, 입체감 0.5, VFG 끔. 각 조건에서 같은 정지 이미지를 16ms마다 다시 그려 5초간 측정했다. GPU 점유율과 전력은 200ms 주기 장치 전체 평균이며, 4K 이미지를 계속 그리는 소스 앱과 데스크톱을 포함한다.

| 모델 | 5초간 새 SBS, 끔 → 켬 | 켬에서 재사용 | GPU 전체 점유율 | GPU 전체 전력 |
| --- | ---: | ---: | ---: | ---: |
| Base | 178 → 5 | 292회 | 89.12% → 46.76% | 241.26 → 126.24 W |
| Small | 294 → 5 | 293회 | 71.32% → 44.48% | 200.96 → 124.12 W |

표시 중인 프레임은 다음 제출까지 유지된다. 재확인용 새 SBS 생성 횟수와 모니터 주사율은 별개다. 캡처 입력을 실제로 멈춘 2초 동안 네 조건 모두 새 입력·렌더·제출은 0회였다. 움직이는 영상 2초 동안 완성 SBS 재사용은 0회였다. 재생 후 다시 정지 이미지를 보낼 때 첫 재사용까지 Base 4.25초, Small 3.23초가 걸렸다.

정지 이미지의 한 픽셀을 바꾸라는 명령부터 그 명령 이후 소스 타임스탬프의 첫 Qt 제출을 관찰하기까지, Base는 43.9 → 51.9ms, Small은 35.3 → 37.2ms였다. 조건별 한 번이며 소스 IPC와 관측 루프를 포함한다. 지연 분포나 실물 표시 지연을 측정한 값은 아니다. 네 조건 모두 종료 후 네이티브 풀과 노드는 0개였다.

원자료는 `out/static-sbs/verified-pixels` 및 `out/static-sbs/verified-native`에 있다. [공개 영상 출처와 조건](../../v1/public_test_media.py)
