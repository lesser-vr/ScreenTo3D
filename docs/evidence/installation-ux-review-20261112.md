# 설치 UX 검토, 2026-11-12

검토 범위는 현재 비공개 1.0.0 릴리스에서 앱을 받고 첫 3D 출력까지 가는 동선이다.
소스·배포 파일·설치 안내에 대한 휴리스틱 평가이며 사용자 관찰 실험 점수가 아니다.

## 판단

변경 전 설치 동선은 **4/10**으로 평가했다. 주요 행동, 다운로드 위치 안내,
기술적인 파일 선택 부담의 세 진단 항목에 각각 심각도 3의 문제가 있어 2점씩 차감했다.
이번 직접 다운로드 링크·일반 ZIP 이름·선택적 추출 도구 안내로 주요 행동 항목을
개선한 뒤의 평가는 **6/10**이다. 인증·필수 팩 수동 선택으로 인한 탐색·인지 부담의
두 주요 항목이 남아 전체 개선 완료로 보지 않는다.

## 권장 최종 흐름

**설치 EXE 하나 다운로드 → 설치 → 실행**을 기본으로 한다. 설치 도우미가
GPU를 판별하고 공통 런타임과 해당 GPU 리소스를 골라 설치한다. 진행률·취소·
실패 후 재시도를 한곳에서 제공한다. 사용자는 SM 번호, 폴더 배치, 추출 스크립트를
선택하지 않는다. Small은 기본 제공하고 FFmpeg·다른 모델·VFG는 필요한 기능을
처음 선택할 때 준비한다. 파일에서 설치는 오프라인·오류 복구 경로로 남긴다.

현재 저장소의 비공개 상태는 유지한다. 다음 중 하나를 결정해야 자동 다운로드를
완결할 수 있다.

- 배포용 파일을 제공하는 별도 공개 HTTPS 원본. 앱·소스 저장소의 공개 여부와
  분리해 구성할 수 있으며 파일 버전·해시·라이선스 고지는 그대로 유지한다.
- 비공개 배포를 유지하면서 사용자가 로그인하는 설치 도우미. 인증정보를 설치 파일에
  넣지 않고 시스템 브라우저를 통한 사용자 인증을 제공해야 한다. 인증 연동 설정은
  별도 작업이다.

완전 오프라인 단일 파일에 모든 GPU 리소스를 넣는 방식은 우선 추천하지 않는다.
현재 앱 ZIP 183 MB + 공통 438 MB + 전체 GPU 팩 1,703 MB만 합해도 약 2.32 GB다.
미디어 도구를 넣기 전부터 현재 GitHub 자산 한도를 넘으며, 필요 없는 리소스도 받게 된다.
이 수치는 현재 ZIP들의 합계이며 새로운 설치 파일의 실제 압축 크기 측정은 아니다.

휴리스틱 목표 10/10에 필요한 나머지 수정은 기술적인 팩 선택과 여러 위치를
오가는 설치·인증 동선을 제거하는 것이다. 그 후 실제 처음 사용하는 사람으로
설치·취소·오프라인·재시도를 확인해야 한다. 이번 작업에서 설치 EXE나 새 인증·
호스팅 서비스는 구현하지 않았다.

## 파일명 변경 검증

릴리스 앱 자산은 `ScreenTo3D-1.0.0-windows-x64.zip`으로 변경했다. GitHub 자산
ID와 182,759,785바이트의 내용·SHA-256은 유지했다. 매니페스트·체크섬·릴리스
안내와 대응 소스 ZIP을 갱신했다. 단일/복수 ZIP의 패키징 검사 2개와 실제
GitHub 재다운로드·체크섬 추출·EXE 실행을 통과했다.
결과는 `out/remove-part01/verified.json`과 `downloaded-launcher.json`에 있다.
바이너리 변경이 없어 기존 GPU·모델·VFG 검증을 재사용한다.
