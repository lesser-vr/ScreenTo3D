# 깊이 경계 보정 내부 해상도 실험

RTX 5090에서 DA2 Small과 Base의 반경 8 기준판을 가로·세로 2/3 해상도 후보와 비교했다. 4K 입력에서 후보는 가이드 명도와 평활 깊이를 2560×1440으로 면적 축소한 뒤, 반경 5에서 선형 보정 계수를 계산한다. 이웃의 폭은 원본 좌표에서 약 16.5픽셀(기준판 17픽셀)이다. 계수를 쌍선형 보간해 원본 명도에 적용한다. 모델 추론, 깊이 이력과 두 눈의 투영은 양쪽에 같은 설정을 적용했다. 추가 GPU 버퍼 없이 기존 작업 버퍼를 재사용했다.

## 동일 프레임 비교

입체감 0.5, detail 후처리, VFG 끔. 5개 공개 영상과 513×289 합성 얇은 선에서 모델마다 36프레임씩, 총 432쌍을 처리했다. 한 번 추론한 깊이로 두 경로를 번갈아 렌더링하고 처음 6프레임을 제외했다. 보정 시간은 축소·복원을 포함하는 CUDA 이벤트 중앙값이다. 윤곽 시차 잔차는 광류로 정렬한 연속 프레임에서 눈당 수평 이동량이 얼마나 달라졌는지 나타낸다. 픽셀 차이 비율은 원본 RGB에서 찾은 윤곽 위치에서 두 SBS 결과의 최대 RGB 채널 차이가 3/255를 초과한 비율이다. 같은 위치로 근사한 윤곽 마스크와 1/4 해상도 광류는 개별 얇은 물체의 지각 품질에 한계가 있다.

## 실제 4K 창 캡처

mpv로 공개 Jockey 4K120 창을 재생해 WGC로 캡처하고 네이티브 7680×2160 Full SBS 창을 열었다. 조건별 10초씩 3회, 출력 제한 60 FPS, 입체감 0.5, VFG 끔, Qt 이벤트 루프와 GPU 캡처를 사용했다. Small은 축소판부터, Base는 원본부터 측정했다. FPS는 세 구간의 중앙값, 점유율과 전력은 구간 내 200ms 주기 장치 샘플의 평균이다.

| 모델 | 출력 FPS, 원본 → 축소 | GPU 전체 점유율 | GPU 전체 전력 |
| --- | ---: | ---: | ---: |
| Small | 59.89 → 60.00 | 38.63% → 36.09% | 210.44 → 196.89 W |
| Base | 59.99 → 59.99 | 56.30% → 54.11% | 309.21 → 300.10 W |

실행 전 대기 상태에서도 GPU 전력은 51–69 W로 차이가 있었다. 재생 중 측정에는 바탕 화면과 플레이어가 포함돼 있으며, 이 한 장치·한 영상의 결과만으로 다른 환경의 절감량을 예측하기 어렵다. 네 조건 모두 종료 후 추적된 네이티브 풀·노드 수는 0이었다. 원자료는 `out/public-hfr/grid-2of3-*.json`에 있다.

4K에서 축소 후보의 시간축 윤곽 잔차는 원본보다 눈당 0.0005–0.0022픽셀 컸다. 기본값은 원본 해상도 반경 8이다. Owl3D에서 움직이는 윤곽과 입체감의 시청 차이는 미검증이다.

실험 경로는 `scripts/build-gpu-load-opt.ps1 -OutputName guide-two-thirds`로 빌드한다. 비교 스크립트는 이 체크아웃에서 검증한 DLL의 SHA-256을 확인한다. `v1/compare_guide_resolution.py --output <새 폴더>`로 같은 조건을 재생한다. `--review`는 Base의 Jockey 3초 구간을 두 개의 60 FPS Full SBS 파일로 저장한다. 프레임별 측정 결과는 `out/guide-two-thirds/paired/`에 있다.
