# ScreenTo3D 1.0.0

2026-11-11 initial release · **2026-11-18 error-reporting refresh** · Windows x64 · `v1.0.0`

## 한국어

게임·영상 창이나 모니터를 실시간 3D로 보고, 영상 파일을 입체 영상으로 변환합니다.
이번 교체본은 실시간 3D 오류의 직전 상태를 저장하고 오류 보고서를 쉽게 공유할 수 있게 합니다.
설정 화면의 구버전 데이터 가져오기 절차도 정리했습니다.
버전과 다운로드 파일명은 1.0.0을 유지합니다.

### 받기 및 실행

1. **[Windows 앱 ZIP 다운로드](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.0/ScreenTo3D-1.0.0-windows-x64.zip)**를 받습니다. 앱 ZIP 하나만 있으면 됩니다.
2. 압축을 모두 풀고 `ScreenTo3D/ScreenTo3D.exe`를 실행합니다. ZIP 내부 폴더명은 버전과 무관하게 `ScreenTo3D`입니다.
3. 업데이트라면 기존 앱 폴더의 `data/`를 보존하세요. 구버전 AppData에만 있던 모델은 앱의 준비 화면에서 다시 받을 수 있습니다.
4. 창이나 모니터를 선택하고 **3D 시작**을 누릅니다. 필요한 파일은 준비 화면에서 안내합니다.

이미 `data/`를 사용하는 버전은 앱을 닫고 같은 앱 폴더의 프로그램 파일을 교체하되
`data/`를 보존하세요. ZIP에는 사용자 데이터가 들어 있지 않습니다. 앱 폴더 전체를
옮기면 설정과 준비된 파일도 함께 이동합니다.

앱 ZIP 다운로드에는 비공개 저장소 접근 권한이 필요합니다. 실행 후 받는 공식 런타임과
별도 공개 Base·VDA 팩에는 GitHub/NVIDIA 로그인이나 API 키가 필요하지 않습니다.
Python·Torch·TensorRT SDK·CUDA Toolkit을 직접 설치할 필요도 없습니다.

### 이번 교체본 변경

- 30/60 FPS 출력의 화면 동기화를 적용하고, 영상 프레임마다 제어창을 다시 그리던 처리를 제거했습니다.
- 원본 창에서 키보드·마우스를 조작하면서 3D를 볼 수 있도록 출력 포커스와 표시 순서를 보완했습니다. 제목표시줄 선택 후 F11을 누르면 전체화면 전환 뒤 원본으로 복귀합니다. 원본 조작 중에는 **Ctrl+Alt+Enter**로 전환할 수 있습니다.
- 메인 화면 **?**와 실시간 출력 설정에 **조작·단축키 안내**를 추가했습니다. 키의 적용 범위와 충돌 시 대체 버튼을 표시합니다. VFG 전환은 **Ctrl+Alt+S**입니다.
- 실제 GUI와 작업 프로세스도 **ScreenTo3D.exe** 이름과 앱 아이콘으로 표시합니다.
- 오류 창의 **보고서 준비…** 또는 **설정 → 최근 오류**에서 오류 한 건을 확인하고 텍스트 파일로 저장할 수 있습니다. 메모를 덧붙이거나 직전 60초 진단을 포함할 수 있습니다.
- 실시간 3D 오류는 직전의 입력·출력 진행과 전환 상태를 `data/logs/errors.jsonl`에 함께 남깁니다. 공유본은 필요한 항목만 담고 원본 경로와 예외 전문은 로컬 기록에 보관합니다.
- 한글·영문·숫자를 **Pretendard**로 통일하고 제목·본문 굵기를 조정했습니다. 글꼴과 라이선스가 포함되어 별도 설치가 필요 없습니다. 기존 8px 성능 정보와 14px VFG 안내 크기는 유지합니다.
- 설정은 레지스트리 대신 `data/settings.ini`, 출력 창 위치는 `data/window-state.json`을 사용합니다.
- 모델은 `data/models`, 런타임·VFG는 `data/runtimes`, 캐시는 `data/cache`, 로그와 임시 파일은 `data/logs`, `data/temp`에서 관리합니다. 쓸 수 없는 경로는 오류로 안내합니다.
- 최초 실행 안내와 구버전 AppData 가져오기 메뉴를 제거했습니다. 설정에서 현재 저장 위치를 확인하고 데이터 폴더를 열 수 있습니다.
- Base·VDA의 사용자·GPU별 엔진 영수증을 확인하고, 호환되지 않는 엔진은 보존하면서 새 엔진을 준비합니다. 새 설치의 검증된 원본 팩은 재빌드에 재사용합니다.
- VDA FP16의 깊이·이력 검증을 구분하고 전체 오차와 이상치 한도를 함께 적용합니다. 종속 단계의 제한된 재빌드로 잘못된 재시도 경로를 보완했습니다. Base와 모델 그래프는 변경하지 않았습니다.
- 내부 패키지·리소스 이름을 ScreenTo3D로 통일했습니다. 기존 실행 진입점과 출력 식별자는 호환을 유지합니다.
- 이전 교체본의 공식 다운로드·오디오/영상 완주·취소 처리·DPI 맞춤·개인 경로/바이트코드 제외 보완도 포함합니다.

DA2 Small FP16은 기본 동봉됩니다. Base 약 **392 MB**, VDA 약 **363 MB**는
고정된 **[공개 모델 릴리즈](https://github.com/lesser-vr/ScreenTo3D-Models/releases/tag/packs-2026.11.1)**에서 받고 사용자 GPU에서 엔진을 만듭니다.
공통·GPU별 설치는 약 **1.96 GB**의 TensorRT 공식 원본을 공유하며 CUDA 약 **3 MB**,
파일 변환용 FFmpeg 약 **97 MB**, 선택적 VFG 약 **436 MB**도 공식 원본에서 받습니다.
버전·크기·전체 해시를 검증하고, 재시도·이어받기와 검증된 다운로드 캐시 재사용을 지원합니다.
설치 캐시와 엔진 용량은 앱 ZIP과 별도입니다. 준비 성공 후 요청한 작업을 이어가며,
취소·오류·선택 변경 뒤에는 작업을 자동 시작하지 않습니다.

기본값: 실시간 **DA2 Small FP16**, 파일 변환 **DA2 Base**, **Half Top-and-Bottom**,
입체감 **0.5**, 출력 제한 **60 FPS**, **VFG 꺼짐**. Full/Half SBS와 Top-and-Bottom,
실행 중 VFG 전환, 순차 파일 변환과 저장된 선택 복원을 지원합니다.

### 검증·소스·실행 조건

**621개 로컬 CPU/Qt 검증이 통과했습니다.** 오류 기록 재열기, 한국어·영어
미리보기와 저장, 공유본에서 내부 경로 제외를 확인했습니다. 모의 D3D11
입력으로 프레임 공백·크기 변경·버퍼 재생성 및 출력 전환 후 재개도 확인했습니다.
이전 배포본의 로컬 4K60 영상 30분 시험은 중단 없이 완료했고 평균 출력 제출은
50.92 FPS였습니다. 실제 Veyra의 과거 오류와 물리 Owl3D 표시 품질은 미검증입니다.

태그와 소스 ZIP은 이번 배포 커밋을 기준으로 갱신합니다. 정확한 앱 파일 해시는
`build-manifest.json`, 소스는 `ScreenTo3D-1.0.0-source-refresh.zip`에서 확인할 수 있습니다.
Windows/Git 줄바꿈 차이를 제외하면 같은 커밋의 코드입니다.

Windows 11 x64, 해당 CUDA/TensorRT가 지원하는 NVIDIA GPU와 CUDA 드라이버 API 13.1+
이 필요합니다. 실행 파일은 코드 서명되지 않았습니다. Base는 CC BY-NC 4.0,
VDA Small은 Apache-2.0이며 NVIDIA 구성요소에는 해당 NVIDIA 조건이 적용됩니다.
라이선스 고지를 보존하세요.

## English

Download the **[Windows app ZIP](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.0/ScreenTo3D-1.0.0-windows-x64.zip)**
and extract everything, then run
`ScreenTo3D/ScreenTo3D.exe`. The archive root is now fixed as `ScreenTo3D/`.
Select a source and Start 3D. Missing dependencies open setup. When updating,
preserve your existing `data/` folder. Models stored only in an older AppData
location can be prepared again through setup.

Preferences use `data/settings.ini`, window placement uses `data/window-state.json`,
and models, runtimes, caches, logs and temporary files all stay under `data/`.
Move the whole app folder. Close the app before updating program files and retain
`data/`; user data is never included in the release ZIP. Settings shows the
data path and the folder-opening action.

This refresh adds synchronized capped output, fewer control-window repaints,
source-input focus preservation and global Ctrl+Alt+Enter fullscreen switching.
The main **?** and Live output settings share a controls/shortcuts guide with
scope and conflict alternatives. GUI and worker processes carry the ScreenTo3D
name/icon. Use **Prepare report…** or **Settings → Recent errors** to preview
and save one error as a text file. A note and up to 60 seconds of shareable live
diagnostics are optional. Bundled
Pretendard unifies Korean/Latin/numerals without a separate font installation;
8px performance text and 14px VFG notices retain their sizes.

It retains user/GPU receipt checks, retained model sources and safe
replacement of incompatible engines, bounded VDA FP16 depth/cache validation with
dependent-stage retries, and consistent internal ScreenTo3D names with legacy entry
compatibility. Earlier media completion/cancellation, DPI, official-download and
private-path/bytecode fixes are retained.

The app release remains private. Official runtime and separate public Base/VDA
model downloads need no account or API key. Small FP16 is bundled. Base (**392 MB**)
and VDA (**363 MB**) build engines on the user's GPU. The TensorRT publisher archive
is about **1.96 GB**, shared across common/GPU setup; CUDA is about **3 MB**, FFmpeg
**97 MB** and optional VFG **436 MB**. Versions, sizes and hashes are pinned;
retries, resume and verified-cache reuse are supported. Existing offline packs stay
optional alternatives. Do not download every GPU pack. Python/Torch/TensorRT SDK/
CUDA Toolkit do not need manual installation.

Defaults remain Small FP16 live, Base for files, Half Top-and-Bottom, strength
0.5, 60 FPS and VFG off. Saved choices, sequential conversion and runtime VFG
switching remain supported.

**621 local CPU/Qt checks pass.** Bilingual checks cover error history,
preview, and export. The D3D11 fixture verified recovery from input pauses,
resizes, buffer rebuilds and output mode changes. A 30-minute local 4K60 video
run of the preceding release had no unexpected stops and averaged 50.92 output
submissions per second. Real Veyra failures and physical Owl3D output remain
unverified.

The v1.0.0 tag and source-refresh ZIP are updated to the release commit.
`build-manifest.json` identifies exact bundled source hashes; the code matches
that commit allowing Windows/Git text line endings. Windows 11 x64, a supported
NVIDIA GPU and CUDA driver API 13.1+ are required. Executables are unsigned.
Preserve Apache/CC BY-NC and NVIDIA notices.
