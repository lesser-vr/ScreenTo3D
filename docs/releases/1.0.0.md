# ScreenTo3D 1.0.0

2026-11-11 initial release · **2026-11-13 distribution refresh** · Windows x64 · `v1.0.0`

## 한국어

게임·영상 창이나 모니터를 실시간 3D로 보고, 영상 파일을 입체 영상으로 변환합니다.
이번 교체본에는 공식 파일 다운로드, 공개 모델 팩 설치, 미디어 처리·창 크기 보완과
개인 경로 정리가 반영됐습니다.

### 받기 및 실행

1. **[Windows 앱 ZIP 다운로드](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.0/ScreenTo3D-1.0.0-windows-x64.zip)**를 받습니다.
2. 기존 앱과 다른 새 폴더에 **압축을 모두 풀고** `ScreenTo3D.exe`를 실행합니다.
3. 창이나 모니터를 선택하고 **3D 시작**을 누릅니다. 필요한 파일은 준비 화면에서 설치합니다.

**앱 ZIP 다운로드에는 현재 비공개 저장소 접근 권한이 필요합니다.** 앱 실행 후 받는
공식 런타임과 공개 Base·VDA 팩은 GitHub/NVIDIA 로그인이나 API 키 없이 다운로드합니다.
Python·Torch·TensorRT SDK·CUDA Toolkit을 직접 설치할 필요는 없습니다.

### 이번 배포본 변경

- 앱 ZIP **182,755,816 bytes (약 183 MB)**, 압축 해제 후 **428,846,137 bytes (약 429 MB)**.
  DA2 Small FP16이 기본 동봉됩니다. 설치 캐시와 생성되는 GPU 엔진의 용량은 별도입니다.
- 공통 TensorRT·GPU 리소스·CUDA·FFmpeg·선택적 VFG는 고정된 공식 원본에서 받습니다.
  버전·크기·SHA-256을 확인하며 재시도·이어받기와 검증된 설치 파일 재사용을 지원합니다.
- TensorRT 최초 공식 원본은 약 **1.96 GB**, CUDA 원본은 약 **3 MB**입니다.
  공통 구성요소와 GPU 리소스가 같은 TensorRT 다운로드 캐시를 공유합니다.
  파일 변환에 필요한 FFmpeg 공식 원본은 약 **97 MB**입니다.
- Base·VDA ONNX 팩은 별도 **[공개 모델 릴리즈](https://github.com/lesser-vr/ScreenTo3D-Models/releases/tag/packs-2026.11.1)**에서 받습니다.
  Base 약 **392 MB**, VDA 약 **363 MB**이며 사용자의 GPU에서 TensorRT 엔진을 만듭니다.
  Base의 비상업용 조건은 유지됩니다.
- 필요한 파일이 없으면 오류 대신 준비 화면으로 진입합니다. 설치 성공 후 요청한
  작업을 이어가며, 취소·오류·설정 변경 후에는 작업을 자동 시작하지 않습니다.
- VDA FP16 엔진 준비 시 캐시 텐서 검증과 제한된 재빌드를 적용합니다.
  최종 깊이 출력 검증은 유지하며 반복 실패는 구체적인 오류로 알립니다.
- 짧은 오디오 때문에 영상 끝이 잘리는 문제를 수정했습니다. 최종 영상 프레임 수·
  크기·길이를 확인하며, FFmpeg 입출력이 막혀도 취소·오류 처리가 진행됩니다.
- 작은 논리 화면·높은 DPI에서도 제어창의 아래쪽 버튼에 접근할 수 있도록 보완했습니다.
- 문서의 개인 파일 경로와 배포 앱에 포함됐던 Python 캐시를 정리했습니다.

기본값은 실시간 **DA2 Small FP16**, 파일 변환 **DA2 Base**, **Half Top-and-Bottom**,
입체감 **0.5**, 출력 제한 **60 FPS**, **VFG 꺼짐**입니다. Full/Half SBS와 Top-and-Bottom,
실행 중 VFG 전환, 순차 파일 변환을 지원하며 사용자가 저장한 선택은 유지합니다.
VFG를 켜면 NVIDIA 공식 약 **436 MB** 원본을 별도로 준비합니다.

## English

Download **[the Windows app ZIP](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.0/ScreenTo3D-1.0.0-windows-x64.zip)**,
extract it into a new folder and run `ScreenTo3D.exe`. Select a source and Start 3D;
missing files open preparation instead of an error. Repository access is currently
required to download this private app release. Runtime downloads from their official
publishers and Base/VDA packs from the separate public model release need no account,
API key, or manual Python/Torch/TensorRT SDK/CUDA Toolkit setup.

The refreshed app ZIP is **182,755,816 bytes (about 183 MB)** and **428,846,137 bytes
(about 429 MB)** extracted. Small FP16 is bundled. The initial TensorRT publisher
archive is about **1.96 GB**, shared by common and GPU-resource setup; CUDA is about
**3 MB** and the FFmpeg publisher archive about **97 MB**. Downloads have fixed
versions/sizes/hashes, bounded retries, resume and verified cache reuse. Engine and
installation caches use additional storage.

Base (**392 MB**) and VDA (**363 MB**) download from the fixed
[public model release](https://github.com/lesser-vr/ScreenTo3D-Models/releases/tag/packs-2026.11.1).
Engines are built on the user's GPU; Base's non-commercial license still applies.
Optional VFG downloads about **436 MB** from NVIDIA and starts disabled. Successful
setup continues the requested task; cancellation, failure or selection changes keep
it stopped. Existing offline packs remain optional file-install alternatives, not
required downloads. The optional checksum extractor handles only the supplied packs;
do not download every GPU pack. `SHA256SUMS.txt` also covers the separate source ZIP.

This refresh includes FP16 reference-validation diagnostics/retries, complete-video
muxing with shorter audio, cancellable media I/O, control-window work-area fitting,
and private-path/bytecode cleanup. Defaults remain Small FP16 live, Base for files,
Half Top-and-Bottom, strength 0.5, 60 FPS and VFG off. Saved selections, Full/Half SBS
and Top-and-Bottom, runtime VFG switching and sequential conversion are retained.

**526 CPU/Qt contracts and [source CI](https://github.com/lesser-vr/ScreenTo3D/actions/runs/43253117571) pass.**
Prepared RTX 5090 checks cover short model conversions/decodes, media failures and
cancellation, work-area fitting, notice/source integrity and extracted EXE launch/close.
Other GPUs, clean machines, sustained 4K output and stereo comfort are not certified.
Windows 11 x64, an NVIDIA GPU supported by CUDA/TensorRT and CUDA driver API 13.1+
are required. Executables are unsigned. Preserve Apache/CC BY-NC and NVIDIA notices.

Application sources match CI commit `f20e9d8f81ac8f82d50d03e8dff00e267c15500b`, allowing
Windows/Git text newline differences. The build manifest truthfully retains base
`bcbae96f6900e6a01a786ba729ee73006d4cf03d` plus its dirty-build flag. Use the provided
`ScreenTo3D-1.0.0-source-refresh.zip` for exact build-time sources and file hashes;
GitHub's automatic tag-source archives do not describe the entire refreshed app.
