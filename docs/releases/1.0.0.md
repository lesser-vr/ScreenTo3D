# ScreenTo3D 1.0.0

2026-11-11 initial release · **2026-11-12 distribution refresh** · Windows x64 · `v1.0.0`

## 한국어

게임·영상 창이나 모니터를 선택해 실시간 3D로 보고, 영상 파일을 입체 형식으로
변환하는 한국어·영어 데스크톱 앱입니다. 이번 교체본은 Small을 기본 동봉하고
공통 TensorRT·미디어 도구를 첫 사용 시 설치합니다.

### 이번 배포본 변경

- 앱 본체 ZIP **182,759,785 bytes (약 183 MB)**, 압축 해제 후 약 429 MB.
  기존 첫 배포본의 앱 ZIP 합계 약 5.80 GB에서 줄었습니다. 설치 캐시는 별도입니다.
- Torch 의존성을 제거한 공통 CUDA 메모리 경로, 공유 FFmpeg, 미사용 개발·Qt 구성 정리.
- 공통 TensorRT·PTX·CUDA 런타임은 약 **438 MB**, GPU별 엔진 생성 리소스는 별도 팩.
  예를 들어 SM120 팩은 약 **272 MB**입니다. 모델 엔진은 사용자 GPU에서 생성합니다.
- FFmpeg·FFprobe는 파일 변환 첫 사용 시 설치하는 약 **92 MB** 팩으로 분리했습니다.
- 필수 구성요소 설치 후 요청한 작업을 이어갑니다. 취소·오류 후에는 자동 실행하지
  않으며, 파일 설치·재시도를 지원합니다. 설치한 구성요소는 다음 실행에서 재사용합니다.
- Full/Half SBS 및 Full/Half Top-and-Bottom. 기본 출력은 Half Top-and-Bottom,
  입체감 0.5, 출력 제한 60 FPS. 기본 실시간 모델은 DA2 Small FP16입니다.
- 선택적인 Base·VDA, 기본 꺼짐인 NVIDIA VFG, 실행 중 VFG 단축키 전환,
  파일 변환의 입체감·VFG·순차 대기열·완료 후 Windows 종료 옵션을 유지합니다.

### 받기 및 실행

1. **[Windows 앱 ZIP 다운로드](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.0/ScreenTo3D-1.0.0-windows-x64.zip)**를 누릅니다.
2. ZIP의 **압축을 모두 풀고** `ScreenTo3D.exe`를 실행합니다.
   별도 추출 스크립트는 필수가 아닙니다. 기존 앱과는 다른 새 폴더를 사용하세요.
3. 창이나 모니터를 선택하고 **3D 시작**을 누릅니다. 처음에는 아래의 필수 팩을 준비해야 합니다.

<details>
<summary>첫 사용에 필요한 팩 준비</summary>

비공개 릴리스이므로 필요한 팩은 GitHub에 로그인해 받아야 합니다.
`tensorrt-11.2.1.2-core-v1.zip`과 앱이 표시하는 GPU 팩을 받아 **파일에서 설치**로
선택합니다. 연결 오류 후 파일 설치를 마쳤다면 **3D 시작**을 다시 누르세요.
파일 변환에는 `ffmpeg-9.0.1-shared-v1.zip`도 준비합니다.

Base·VDA가 필요할 때만 `ScreenTo3D-1.0.0-optional-models.zip`을 받아 압축을 풀고
앱의 로컬 팩 설치를 사용합니다. VFG는 앱에서 NVIDIA 공식 파일을 별도로 받습니다.

GPU 팩은 SM75·80·86·89·90·100·120 중 앱이 표시하는 것을 선택하세요.
일치하는 팩이 없는 경우에만 `tensorrt-11.2.1.2-all.zip`을 사용합니다.
모든 GPU 팩을 받을 필요는 없습니다.

</details>

<details>
<summary>선택 사항: 체크섬 검사와 여러 팩을 함께 준비하는 추출 도구</summary>

`Extract-ScreenTo3D.cmd`, `Extract-ScreenTo3D.ps1`, `release-manifest.json`을 앱 ZIP과
같은 폴더에 받습니다. CMD는 SHA-256을 확인하고 새 폴더에만 압축을 풉니다.
함께 받은 런타임 ZIP은 앱 옆 `runtime-packs/`에 복사되어 첫 사용 시 자동 설치됩니다.
나중에 직접 그 폴더에 팩을 두어도 됩니다. `SHA256SUMS.txt`로 자산을 검증할 수 있습니다.

</details>

**이 저장소는 비공개입니다.** 릴리스 파일을 받으려면 저장소 접근 권한이 필요합니다.
앱에는 GitHub 인증정보를 넣지 않았으며, 비공개 릴리스 URL을 자동 다운로드 주소로
설정하지 않았습니다. 필요한 팩을 로그인한 GitHub에서 받아 준비하세요. 별도의 공개
HTTPS 원본을 설정한 빌드에서는 앱 내 다운로드를 사용할 수 있습니다.

### 실행 조건·검증 범위·소스

Windows 11 x64, 해당 CUDA/TensorRT가 지원하는 NVIDIA GPU와 CUDA 드라이버 API
13.1 이상이 필요합니다. Python·Torch·TensorRT SDK·CUDA Toolkit을 수동 설치할
필요는 없습니다. 첫 사용의 엔진 생성과 캐시에는 추가 시간·공간이 필요합니다.
전체 기능 설치 후의 디스크 용량과 총 다운로드량이 앱 본체 용량만큼 작아지는 것은 아닙니다.

267개 core/profile/Qt 계약, 번역 787개·오류 ID 149개, Qt 의존성 검사를 통과했습니다.
RTX 5090에서 설치 취소·재시도, 실제 Small 네이티브 출력, Base/VDA 엔진 생성과
수치 검증, VFG 전환, 큐 변환 및 출력 프레임·오디오 디코딩을 확인했습니다.
다른 GPU·깨끗한 PC·장시간 4K 출력·실제 3D 디스플레이의 편안함은 이 검증에 포함되지 않습니다.
실행 파일은 코드 서명되지 않았습니다. Base는 CC BY-NC 4.0, VDA Small은 Apache-2.0,
NVIDIA 구성요소에는 해당 NVIDIA 조건이 적용됩니다. 라이선스 고지를 보존하세요.

이 교체는 배포 자산 갱신이며 `v1.0.0` Git 태그는 유지합니다. 바이너리의 기반
커밋은 `71b9216419fbdf5ddef6ad17db011a625d6910b4`이고 빌드 당시 미커밋 변경이
포함됐습니다. 이 기능 변경은 현재 [main의 커밋](https://github.com/lesser-vr/ScreenTo3D/commit/52c71844bcabc6a4e4fdce17e1cb92b52f01b299)에도 반영됐습니다.
정확한 빌드 당시 소스는 **`ScreenTo3D-1.0.0-source-refresh.zip`**으로 별도 제공합니다.
앱과 소스 ZIP의 빌드 매니페스트에서 정확한 파일 해시를 확인할 수 있습니다.

## English

This refreshed 1.0.0 distribution provides live desktop 2D-to-3D and stereo file
conversion. The application ZIP is **182,759,785 bytes (about 183 MB)**, about
429 MB extracted. DA2 Small remains bundled. Common TensorRT/PTX/CUDA components
(about 438 MB), the selected GPU resource and media tools (about 92 MB) install
on first use and are cached. Optional models and VFG remain separate.

Download **[the Windows app ZIP](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.0/ScreenTo3D-1.0.0-windows-x64.zip)**,
extract it into a new folder and run `ScreenTo3D.exe`. Extraction scripts are optional.
For first use, download `tensorrt-11.2.1.2-core-v1.zip` and the GPU pack
shown by the app; SM120 is about 272 MB. Add `ffmpeg-9.0.1-shared-v1.zip` for file
conversion. Install original packs from files; press Start again after recovery
from a connection error. Optionally, the checksum-verifying extractor copies supplied packs into `runtime-packs/` beside the
app, or they can be installed later from their original files. Do not download
all GPU packs. Run `ScreenTo3D.exe`, select a source and Start. Successful setup
continues that task; cancellation or failure keeps it stopped. Optional Base/VDA
packs are inside the optional-models ZIP. VFG downloads separately from NVIDIA.

**Repository access is required for these private release downloads.** No GitHub
credentials or private release URL are embedded as an anonymous download origin.
Obtain original packs while signed in, then use local installation. Builds with
a separately configured public HTTPS origin support in-app downloading.

Defaults remain Small FP16 for live, Base for files, Half Top-and-Bottom,
strength 0.5, 60 FPS and VFG off. Full/Half SBS and Top-and-Bottom, runtime VFG
switching and sequential conversion are retained. All-feature downloads, engine
caches and installed components are additional to the small application archive.

Windows 11 x64, a supported NVIDIA GPU and CUDA driver API 13.1+ are required.
No manual Python/Torch/TensorRT SDK/CUDA Toolkit setup is needed. 267 scoped
contracts and actual RTX 5090 setup, fresh model validation, native output,
VFG and decoded file/audio checks pass. Other GPUs, clean machines, sustained 4K
and stereo comfort are not certified. Executables are unsigned. Base weights
are CC BY-NC 4.0, VDA Small is Apache-2.0; preserve applicable NVIDIA notices.

The existing Git tag is preserved. These binaries were built before committing
the changes over base `71b9216419fbdf5ddef6ad17db011a625d6910b4`. Those features
are now also [committed on main](https://github.com/lesser-vr/ScreenTo3D/commit/52c71844bcabc6a4e4fdce17e1cb92b52f01b299).
The exact build-time source snapshot is `ScreenTo3D-1.0.0-source-refresh.zip`, with file/build hashes.
GitHub's automatic tag-source archives still describe the original tag.
