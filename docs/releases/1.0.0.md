# ScreenTo3D 1.0.0

2026-11-11 · Windows x64 · `v1.0.0`

## 한국어

ScreenTo3D의 첫 정식 버전입니다. 게임·영상 창이나 모니터를 선택해 실시간 3D로
보고, 영상 파일을 입체 형식으로 변환할 수 있습니다.

- 미니멀한 한국어·영어 UI와 시스템 언어 선택, 실행 중 언어 전환.
- 실시간 DA2 Small FP16 기본값, 선택적 DA2 Base·VDA Small과 사용자 GPU의
  TensorRT 엔진 생성. 가중치와 네이티브 모듈의 무결성 검증을 유지합니다.
- Full/Half SBS 및 Full/Half Top-and-Bottom. 기본 출력은 Half Top-and-Bottom,
  입체감은 0.5, 출력 제한은 60fps입니다.
- 기본 꺼짐인 NVIDIA VFG와 실행 중 단축키 전환, 타이틀바·선택적 디버그 오버레이.
- 파일 변환의 전체 설정, 입체감·VFG, 형식별 자동 파일명, 순차 대기열,
  선택적인 전체 완료 후 Windows 종료와 취소 가능한 30초 대기.
- 복사 가능한 오류 ID·설명, 툴팁 보완, 실제 UI와 Half TB 예제를 담은 이중 언어 README.

### 받기 및 실행

1. 릴리스 자산의 `ScreenTo3D-1.0.0-windows-x64-part*.zip`을 **모두** 받습니다.
   각 ZIP은 독립된 파일들을 담으며, 원본 파일을 바이트 단위로 나눈 분할 ZIP이 아닙니다.
2. `Extract-ScreenTo3D.cmd`, `Extract-ScreenTo3D.ps1`, `release-manifest.json`도
   같은 폴더에 받습니다. CMD를 실행하면 모든 필수 ZIP의 SHA-256을 검사한 뒤
   새 `ScreenTo3D-1.0.0-bundle` 폴더에 압축을 풉니다. 기존 폴더는 덮어쓰지 않습니다.
3. 생성된 폴더 안의 `ScreenTo3D-1.0.0/ScreenTo3D.exe`를 실행합니다.
   Python·CUDA Toolkit·TensorRT SDK·FFmpeg를 따로 설치할 필요는 없습니다.
4. Base·VDA가 필요하면 `ScreenTo3D-1.0.0-optional-models.zip`도 함께 받습니다.
   추출 도구가 앱 옆에 `packs/`를 만들면 앱의 **로컬 팩 설치**로 설치합니다.
   나중에 받은 경우 직접 압축을 풀고 앱의 **파일에서 설치**로 내부 모델 ZIP을 선택할 수도 있습니다.
   VFG는 앱에서 NVIDIA 공식 파일을 별도로 내려받습니다.

필수 ZIP을 같은 새 폴더에 수동으로 풀어 합쳐도 됩니다. GitHub 자산의 파일당
[2 GiB 제한](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases#storage-and-bandwidth-quotas)에
맞춰 여러 ZIP으로 제공합니다. `SHA256SUMS.txt`로 다른 릴리스 자산도 검증할 수 있습니다.
저장소의 기존 접근 권한이 릴리스에도 적용됩니다.

### 실행 조건 및 범위

Windows 11 x64와 번들 CUDA·PyTorch·TensorRT가 지원하는 NVIDIA GPU 및 드라이버가
필요합니다. 현재 런타임은 CUDA 드라이버 API 13.1 이상을 요구합니다. 첫 사용 때
GPU별 엔진을 준비하므로 시간이 걸릴 수 있고 모델에 따라 추가 공간이 필요합니다.
로컬 실기기 검증 환경은 RTX 5090입니다. 다른 GPU·깨끗한 PC·장시간 4K 재생·실제
3D 디스플레이의 편안함까지 검증됐다는 뜻은 아닙니다. oVDA 연구 모델은 동봉하지 않습니다.
Base 가중치는 CC BY-NC 4.0, VDA Small은 Apache-2.0이며 NVIDIA VFG에는 별도 NVIDIA
조건이 적용됩니다. 패키지의 라이선스 파일을 보존하세요.

## English

The first ScreenTo3D release combines live 2D-to-3D desktop capture and stereo
video file conversion with a compact Korean/English interface.

- DA2 Small FP16 by default for Live 3D; optional DA2 Base and VDA Small with
  TensorRT engine compilation on the user's GPU, preserving integrity checks.
- Full/Half SBS and Full/Half Top-and-Bottom. Defaults: Half Top-and-Bottom,
  depth strength 0.5 and a 60fps output limit.
- Optional NVIDIA VFG, disabled by default, with live shortcut switching and
  output diagnostics. File conversion has its own strength and VFG controls.
- Sequential file queues, layout-aware filenames, visible file settings and
  optional Windows shutdown after complete queue success with a cancelable delay.
- Runtime language switching, copyable error IDs and messages, improved
  tooltips, and illustrated English/Korean documentation.

### Download and run

Download **all** `ScreenTo3D-1.0.0-windows-x64-part*.zip` application archives plus
`Extract-ScreenTo3D.cmd`, `Extract-ScreenTo3D.ps1` and `release-manifest.json` into
the same folder. Run the CMD to verify hashes and extract into a new
`ScreenTo3D-1.0.0-bundle` directory, then run its
`ScreenTo3D-1.0.0/ScreenTo3D.exe`. The independent ZIPs can alternatively be
extracted manually into the same new directory. Existing destinations are not
overwritten. Python, the CUDA Toolkit, TensorRT SDK and FFmpeg are bundled.

Optionally download `ScreenTo3D-1.0.0-optional-models.zip` before extraction to
place pinned Base/VDA packs next to the app, then choose the local pack installer.
It can also be extracted later and its inner model ZIPs selected in the app's
file installer. VFG is downloaded separately from NVIDIA; it is not bundled.
Repository access permissions also apply to these release downloads.

Windows 11 x64, a supported NVIDIA GPU and CUDA driver API 13.1 or newer are
required. First-use engine compilation needs additional time and space.
Local hardware validation used an RTX 5090; other GPUs, clean machines,
sustained 4K output and physical stereo comfort are not certified by that test.
Experimental oVDA is not bundled. Base weights are CC BY-NC 4.0; VDA Small is
Apache-2.0. Preserve the bundled license notices and NVIDIA terms.
