# ScreenTo3D 1.0.1

2026-11-24 · Windows x64 · v1.0.1

## 한국어

실시간 출력 설정, 일반 설정, 파일 변환에서 스크롤 영역 가장자리의 버튼을 클릭할 때 버튼이 움직이거나 클릭이 취소되던 문제를 수정했습니다. **Tab**과 **Shift+Tab**으로 이동하면 선택한 항목이 보이도록 자동 스크롤됩니다.

**[Windows 앱 ZIP 다운로드](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.1/ScreenTo3D-1.0.1-windows-x64.zip)** 후 압축을 모두 풀고 ScreenTo3D.exe를 실행하세요. 업데이트 시 앱을 닫고 기존 data/ 폴더를 보존하세요. 모델과 런타임은 준비 화면에서 확인할 수 있습니다.

Windows 11 x64와 CUDA Compute Capability 7.5 이상을 지원하는 NVIDIA GPU, CUDA 13.1 이상을 지원하는 NVIDIA 드라이버가 필요합니다. DA2 Small은 앱에 포함되며, 새 환경에서는 기본 실시간 3D에 약 2 GB, DA2 Base 파일 변환에 약 2.45 GB의 추가 다운로드가 필요합니다. [상세 설치와 1.0.0 오프라인 팩](1.0.0.md)

## English

Fixed a scroll jump on mouse press that could cancel clicks near the edge of a scroll area in Live output settings, Settings and diagnostics, and File conversion. **Tab** and **Shift+Tab** still scroll the focused control into view.

**[Download the Windows app ZIP](https://github.com/lesser-vr/ScreenTo3D/releases/download/v1.0.1/ScreenTo3D-1.0.1-windows-x64.zip)**, extract it, and run ScreenTo3D.exe. Close the app before updating and keep the existing data/ folder. Setup shows the models and runtimes required for your selection.

Requires Windows 11 x64, a supported NVIDIA GPU with CUDA Compute Capability 7.5 or later, and a driver supporting CUDA 13.1 or later. DA2 Small is bundled. Fresh installs download about 2 GB for default Live 3D or 2.45 GB for DA2 Base file conversion. [Setup details and 1.0.0 offline packs](1.0.0.md)
