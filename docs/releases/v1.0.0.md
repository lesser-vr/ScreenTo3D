# DepthSBS v1.0.0

Release type: Windows portable release

## User outcome

Users can launch `DepthSBS.exe`, choose a local video and one of four modes, and
produce a full side-by-side H.264 MP4 with AAC audio. No project Python, CUDA
Toolkit, TensorRT SDK, or separate FFmpeg installation is required.

## Validated environment

- Windows 11 x64
- NVIDIA GeForce RTX 5090, compute capability 12.0
- TensorRT 11.2.1.2 runtime and builder
- FFmpeg 9.0.1
- DA2 Small FP16 ONNX SHA-256
  `2df6223f206b5164e21f664ace61dabeb9bb6a49b8b5a3e00510b4807d0f5b04`

## Release evidence

- Packaged diagnostics found one CUDA device, TensorRT 11.2.1.2, the bundled
  model, and the LocalAppData engine cache.
- A 1280 x 720, 30 fps, 2 second H.264 + AAC fixture produced 60 H.264 frames at
  2560 x 720 with a 2 second AAC stream.
- Performance, Balanced, Video Quality, and Offline Quality each completed a
  packaged six-frame H.264 + AAC fixture.
- Cancellation after three 720p frames returned the cancellation status and
  left no final file, partial file, video-only file, or FFmpeg child process.
- An isolated packaged run succeeded with external FFmpeg, `TensorRT_PATH`, and
  `CUDA_PATH` removed from the process environment.
- The GUI opened with the expected `DepthSBS v1` window title.
- The DA2 TensorRT FP16 result passed the pinned FP32 numerical oracle.

## Performance observation

The correctness-oriented CPU/GPU hybrid processed the 720p fixture at about
2.0 fps when the first-run engine build was included. A cached-engine 320 x 180
fixture processed at about 10.5 to 11.1 fps across modes. These are development
observations, not broad hardware claims.

## Known limitations

- NVIDIA-only; no silent CPU inference fallback.
- H.264 full-SBS MP4 output.
- Every mode uses DA2 Small in V1 and varies policy rather than model identity.
- CPU decode transfer and stereo synthesis prevent zero-copy claims.
- HDR/rotation metadata preservation and code signing remain future work.
- The portable directory is large because it includes TensorRT builder
  resources for multiple NVIDIA GPU architectures and a full FFmpeg build.
