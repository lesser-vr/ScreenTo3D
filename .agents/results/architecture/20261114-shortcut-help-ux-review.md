# 단축키 안내 UX 검토

- 날짜: 2026-11-14
- 범위: 현재 Python/QML 소스의 단축키 안내와 진입 경로. UI 구현 변경 없음. 실제 사용자 발견성 테스트나 스크린샷 시각 평가는 수행하지 않음.
- 평가: 단축키 안내 범위 7/10, 최고 심각도 2(경미). 앱 전체 점수가 아니다. 안내 진입의 발견성, 단축키 적용 범위의 구분, 등록 충돌의 표시가 각각 부족한 것으로 평가했다.

## 현재 안내

| 기능 | 안내 위치 | 입력 적용 범위 |
|---|---|---|
| Ctrl+Alt+Enter 전체화면 전환 | 출력 제목표시줄, 실시간 출력 설정 하단 전체화면 버튼 옆 ? | 출력 실행·표시 중 전역. 원본 입력 중에도 사용 |
| Ctrl+Alt+S VFG 전환 | 출력 우클릭 메뉴, 실시간 출력 설정의 VFG 옆 ? | 앱 전역 등록. 재생 중 전환 지원. 유휴 상태에서는 다음 실행 설정 변경, 파일 작업 중/전환 중 등에는 제한 |
| F11 창/전체화면 전환 | 출력 우클릭 메뉴, 설정 하단 ? | 3D 창이 키보드 입력을 받는 동안. 제목표시줄 클릭 후 F11 흐름 지원 |
| Esc 전체화면 종료 | 전체화면 상태 우클릭 메뉴, 설정 하단 ? | 3D 창에 키보드 입력이 있을 때. 원본 포커스에서 Esc는 원본으로 전달됨 |

- `LivePage.qml`: 기본 화면에 단축키 안내 진입이 없다. 설정 아이콘은 LiveOptions로 연결된다.
- `LiveOptions.qml`: VFG 안내와 창 조작 안내가 떨어져 있고 창 조작 안내는 스크롤 하단이다.
- `HelpButton.qml`: 마우스 hover와 키보드 focus 모두 팝업 표시를 지원한다. 따라서 hover 전용이라는 결함은 없다. 한 곳에서 안내를 계속 읽는 구조는 아니다.
- 등록 충돌 문구는 Python의 outputShortcut/vfgShortcut에 반영되지만 해당 도움말을 열어야 확인된다. 제목표시줄/메뉴는 정적 키 이름을 계속 표시한다.
- `VfgNotice.qml`는 준비/ON/OFF 피드백을 표시하는 재생 중 알림이며 단축키를 처음 알려주는 안내는 아니다.

## 권장안

1. **기본 화면 상단 설정 아이콘 옆에 작은 ? 한 개**를 둔다. hover/focus 설명은 ‘조작·단축키 안내’. 클릭 또는 Enter/Space로 읽는 동안 유지되는 popover를 열고, 바깥 클릭/Esc/닫기로 닫는다. 큰 도움말 창이나 기본 화면의 긴 설명은 추가하지 않는다.
2. 안내 안에서 **원본 창 조작 중에도 사용**(Ctrl+Alt+Enter, Ctrl+Alt+S)과 **3D 창 선택 시 사용**(F11, Esc)을 분명히 나눈다. 키 배지+동작명으로 훑어볼 수 있게 한다.
3. 하단에 ‘키보드와 마우스는 원본 창에서 조작하세요. 제목표시줄을 클릭한 뒤 F11을 누르면 전체화면 전환 후 원본으로 돌아갑니다.’를 짧게 제공한다. 실제 이동/크기 조절은 마친 즉시 원본 복귀한다는 차이는 추가 설명에 둔다.
4. 같은 안내를 실시간 출력 설정의 ‘조작·단축키’ 항목에서도 연다. VFG ?는 모델/준비/지연 등 기능 설명을 유지하고 단축키 도움말의 중복 원본으로 쓰지 않는다. 하나의 정의에서 키/동작/범위/등록 상태/번역을 공급해 메뉴·도움말 문구가 어긋나지 않게 한다.
5. 단축키가 다른 앱과 충돌하면 안내 내 해당 행에 ‘다른 앱이 사용 중’과 버튼 대안을 표시한다. 재생 시작 때 전역키 등록 실패가 확정되면 메인 상태 근처에서 짧은 비차단 알림으로 알려 숨겨진 도움말에만 의존하지 않는다. 오류창은 사용하지 않는다.

기본 화면의 ? + 재사용 안내 popover + 설정 진입 + 적용 범위/충돌 표시까지를 1차 개선 범위로 권장한다. 매 실행 자동 팝업/상시 3D 오버레이/추가 안내 단축키는 1차에 넣지 않는다. 기존 VFG 피드백과 게임 화면을 방해하지 않는 것이 목적이다.

## 10/10 수용 조건

- 처음 보는 사용자도 설정을 탐색하지 않고 안내 진입을 찾고, 원본 포커스에서 전체화면 키를 고를 수 있다.
- F11/Esc가 게임에서 동작하지 않는 이유를 안내만으로 이해할 수 있다.
- 마우스와 Tab/Enter/Esc로 동일하게 안내를 열고 읽고 닫을 수 있다. 이름/설명/읽기 순서를 스크린리더에서도 확인한다.
- 한국어/영어, 좁은 창, 긴 번역에서도 키와 설명이 잘리지 않는다.
- 등록 실패·VFG 비가용 상태에서 누를 수 있는 버튼 대안을 찾을 수 있다.
- 기존 원본 포커스 정책과 VFG 알림을 유지한다. 구현 검증과 실제 사용자/장치 수용 결과는 별도로 기록한다.
